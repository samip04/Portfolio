🌐 My Portfolio Website

A modern personal portfolio website built using HTML, CSS, and JavaScript featuring a futuristic neon user interface, smooth animations, and interactive components.
The project demonstrates frontend development skills through responsive design, creative UI effects, and dynamic user interactions.

This portfolio is designed to showcase skills, projects, and contact information in a visually appealing and professional way.

📌 Project Overview

The Neon Portfolio Website is a fully responsive and interactive website created to present personal information in a modern digital format.

The design focuses on:

Clean layout
Smooth user experience
Creative animations
Interactive elements
Responsive design for all devices

The website includes multiple visual enhancements such as glowing neon effects, animated particles background, smooth scrolling navigation, and interactive hover effects.

This project highlights knowledge of frontend technologies and demonstrates the ability to combine design and programming effectively.

📄 File Description
1️⃣ index.html

This file contains the main structure of the portfolio website.

It includes:

Navigation bar
Hero section with introduction
Profile image container
Skills section
Projects section
Contact form
Interactive buttons
Canvas element for animated particle background
Greeting message section

HTML defines the layout and structure of the website content.

2️⃣ style.css
This file controls the appearance and layout of the website.

Key styling features:

Neon color theme
Responsive layout for mobile, tablet, and desktop
Animated hover effects
Section spacing and alignment
Profile image styling and glow effects
Background gradient effects
Custom cursor styling
Scroll progress bar styling
Smooth transitions and animations

CSS ensures the website looks visually appealing and professional.

3️⃣ script.js
This file adds functionality and dynamic behavior to the website.
Main features implemented using JavaScript:
Photo Effects
Users can switch between multiple photo styles:

Normal mode
Neon glow mode
Grayscale mode

Photo effects can also auto-change after a time interval.

Typing Animation

The main heading text appears with a typing animation effect when the website loads.

Smooth Scrolling Navigation

Navigation links scroll smoothly to sections of the page, improving user experience.

Scroll Animations

Sections become visible with animation when scrolling through the page.

Contact Form Validation

The contact form checks that all fields are filled before submission and displays success or error notifications.

Notification System

Interactive notification messages appear when actions are performed such as:

form submission
switching photo effects
activating features
Animated Particle Background

The website includes animated particles in the background to create a futuristic visual effect.

Custom Cursor Effect

A glowing cursor effect enhances the modern design of the website.

Scroll Progress Indicator

A progress bar shows how much of the page has been scrolled.

3D Tilt Image Effect

The profile image tilts slightly in 3D perspective when the mouse moves over it.

Time-Based Greeting Message

The website displays greeting text based on the user's local time:

Good Morning
Good Afternoon
Good Evening
Good Night
Floating Emoji Interaction

Users can interact with a floating emoji element that changes when clicked.

Keyboard Shortcuts
Keyboard keys can trigger certain actions such as switching photo effects.
